# Документация FOCA-rs

[English](../README.md) | Русский

↑ [Корень репозитория](../../README.ru.md)

FOCA-rs 2.0.0-beta.4.1: Android-приложение (Tauri 2 + чисто-Rust ядро из 11 крейтов) для OSINT, форензики метаданных документов и анализа поверхности атаки. Документация на русском языке (основная английская документация: в [`docs/`](../README.md)); удобно читать на GitHub и в Obsidian (относительные ссылки, у каждого документа: `↑` наверх и оглавление).

## Решения (ADR) и стандарты

- [Индекс ADR](../adr/README.md), 12 архитектурных решений: только Android, ванильный JS, SQLite на проект, `panic=unwind`, нативный мост, поисковики через WebView, порты без root, пассивный режим, ключи-опция, перенос логики вместо бинарников, без автокапчи и публичных прокси.
- [Соответствие стандартам](../STANDARDS.md): MITRE ATT&CK v20, CWE (Top 25), OWASP Top 10:2025/WSTG, ISO/IEC 27001:2022, NIST SP 800-53 / НД ТЗІ 3.6-006-24, GDPR / Закон 2297-VI, НД ТЗІ 2.5-004-99 и 3.7-003-05 (для систем с КСЗИ).
