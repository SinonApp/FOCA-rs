# Глоссарий

↑ [Руководство пользователя](README.md) · [Документация](../README.md)

Основные термины OSINT, информационной безопасности и FOCA-rs: синхронизированы со встроенным офлайн-глоссарием (Помощь → Глоссарий, `locales/{en,ru,uk}/help.json`, экран `ui/screens/help.js`), плюс ключевые технические термины документации. Внутренние термины разработки (снапшот, этап, класс доступа) описаны в [архитектуре](../../dev/architecture.md).

| Термин | Значение |
|---|---|
| **AD FS** | Локальный сервер входа Microsoft в сети организации; при федерации он проверяет корпоративные пароли вместо облачного Entra ID. |
| **ASN** | Номер автономной системы: сети провайдера или крупной организации (показывается в RDAP; не является прямой целью скана). |
| **AXFR** | Перенос зоны DNS: запрос всей зоны у сервера имён. Если сервер его разрешает публично, утечка всех записей зоны. |
| **CAA** | DNS-запись со списком удостоверяющих центров, которым разрешено выпускать TLS-сертификаты для домена. |
| **Chain of Custody** | Криптографический блок доказательной цепочки (`CustodyRecord`, sidecar `.sha256` и подпись `ECDSA P-256` `.sig.json` в Android Keystore), подтверждающий целостность отчёта и исходных данных. |
| **Choke Point (точка блокировки)** | Узел минимального разреза в графе путей компрометации, устранение которого разрывает одновременно максимальное число цепочек атаки. |
| **CIDR** | Запись блока сети: `203.0.113.0/24`, 256 адресов IPv4. |
| **CPE** | Стандартный идентификатор программы и версии для точного сопоставления диапазонов CVE. |
| **CT-логи** | Публичные журналы Certificate Transparency: все выданные TLS-сертификаты, раскрывающие действующие и исторические поддомены. |
| **CVE** | Идентификатор публично известной уязвимости, например `CVE-2021-41773`. |
| **CVSS** | Оценка критичности уязвимости по шкале от `0.0` до `10.0`. |
| **DKIM** | Криптографическая подпись исходящих писем ключом домена; публичный ключ публикуется в DNS. |
| **DMARC** | DNS-политика обработки писем, не прошедших SPF/DKIM. Без DMARC проще подделать письмо от имени домена. |
| **DoH** | DNS через HTTPS: запросы имён шифруются и корректно идут через настроенный прокси. |
| **EOL** | End of Life: программа или ОС больше не получает обновлений безопасности. Документ из такой программы: сигнал проверить парк рабочих станций. |
| **EXIF** | Метаданные фотографий: камера, серийный номер, дата, миниатюра и иногда GPS-координаты. |
| **`.foca.enc` (криптоконтейнер)** | Зашифрованный переносимый архив проекта (`FOCAENC1`: `PBKDF2-HMAC-SHA256` + `ChaCha20-Poly1305` + `CustodyManifest`) для безопасной передачи или бэкапа. |
| **k-анонимность (HIBP)** | Проверка утечки секрета, при которой наружу уходят только первые 5 символов локального SHA-1 (`/range/<префикс>`) с `Add-Padding: true`; сам пароль никогда не покидает телефон. |
| **Kill switch** | Автоматическая остановка или пауза скана при обрыве VPN/прокси, чтобы не раскрыть реальный IP-адрес. |
| **M365 tenant** | Арендатор организации в Microsoft 365 / Entra ID: идентификатор, связанные домены и метод аутентификации. |
| **MTA-STS** | Политика домена, требующая обязательного TLS-шифрования при доставке почты на его серверы. |
| **NS** | Авторитативные серверы имён домена, отвечающие на DNS-запросы о нём. |
| **NSEC** | Запись DNSSEC, указывающая на «следующее имя» в зоне; без NSEC3 позволяет обойти и перечислить всю зону. |
| **Origin** | Реальный сервер за CDN. Если он отвечает напрямую, защиту CDN можно обойти. |
| **pHash** | Перцептивный 64-битный хеш (`dHash`/`pHash`) для кластеризации визуально похожих скриншотов веб-сервисов по расстоянию Хэмминга. |
| **PII (ПДн)** | Персональные данные: РНОКПП, IBAN, карты, паспорта, телефоны. В FOCA-rs всегда хранятся только в маскированном виде. |
| **Playbook (план исправления)** | Пошаговая контекстная инструкция устранения в карточке находки с оценкой трудоёмкости, ролями, безопасными командами и чек-листом проверки. |
| **RDAP** | Современная JSON-замена WHOIS: показывает владельца IP-сети или домена. |
| **SAN** | Subject Alternative Name: список имён хостов в TLS-сертификате. Чужие имена попадают в «Кандидаты вне скоупа». |
| **SPF** | DNS TXT-запись со списком серверов, которым разрешено отправлять почту от имени домена. |
| **STIX 2.1** | Стандартный JSON-бандл OASIS Threat Intelligence, экспортируемый FOCA-rs для MISP, OpenCTI и SIEM. |
| **Thinking (рассуждения ИИ)** | Нативные параметры рассуждений облачных ИИ-моделей (`auto`/`off`/`minimal`/`low`/`medium`/`high`/`xhigh`/`max`, бюджет токенов, опциональный просмотр хода мыслей). |
| **TSA** | Сервер меток времени (RFC 3161): криптографически подтверждает момент подписания документа. |
| **vhost** | Виртуальный хост: несколько сайтов на одном IP, различаются по заголовку HTTP `Host`. |
| **WAF** | Межсетевой экран веб-приложений, блокирующий подозрительные или слишком частые запросы. |
| **w:vanish** | Свойство прогона Word, скрывающее текст на экране и при печати при сохранении его внутри XML документа. |
| **XMP** | Блок метаданных Adobe внутри файла: история правок, программы, `DocumentID`, `DerivedFrom`. |
| **Активная фаза** | Запросы с заметным воздействием на цель: `AXFR`, `NSEC`, скан TCP-портов, перебор путей на сайте, активные веб-пробы. Только в «Полном» (или «Своём» с этими модулями) и строго по письменному разрешению. |
| **Важность** | Критический, Высокий, Средний, Низкий, Инфо: приоритет устранения находки. |
| **Веб-архив** | Сохранённые снимки страниц и файлов (Wayback Machine, Common Crawl, Arquivo.pt), позволяющие найти документы даже после удаления с сайта. |
| **Встроенный браузер** | Скрытый Android WebView, через который ядро опрашивает Startpage, Brave Search, Yahoo и публичные SearXNG (`RenderFetcher.kt`). |
| **Дорк** | Поисковый запрос с операторами (`site:example.com filetype:pdf`) для поиска публичных документов через поисковики. |
| **ЄДРПОУ** | Код организации в Едином госреестре Украины (8 цифр): публичная информация (уровень «Инфо»). |
| **Инфостилер** | Вредоносное ПО, похищающее пароли из браузера; HudsonRock показывает URL домена из таких журналов. |
| **Исключение** | Хост, IP или сеть, к которым нельзя обращаться, даже если они входят в цели. Исключения всегда важнее целей. |
| **Канарейка** | Заведомо закрытый порт, немаршрутизируемый адрес `TEST-NET` или DNS/TLS-проба (`foca-net::canary`) для выявления подмены соединений локальным VPN/прокси. |
| **Капча** | Проверка «вы не робот». Решается вручную через «Пройти проверку»; автоматического обхода нет. |
| **КЕП** | Квалифицированная электронная подпись (Украина): сертификат содержит ФИО, должность, организацию, ЄДРПОУ и РНОКПП (хранится маской). См. [Документы](documents.md#форензика-в-карточке-документа). |
| **Краулер** | Обход страниц сайта цели по ссылкам для поиска документов. Обращается к цели. |
| **Листинг каталога** | Открытая страница `Index of /` со списком файлов папки на веб-сервере. |
| **Ложное срабатывание** | Находка, которая на деле не является проблемой. Статус «Ложная» исключает её из отчёта и сохраняется при перескане. |
| **Метаданные** | Скрытые поля файла: автор, логин, программа, путь на диске, принтер, история правок, даты. |
| **Мягкий 404** | Ответ сервера `200 OK` со страницей-заглушкой на несуществующий адрес; отсеивается калибровкой. |
| **Находка** | Конкретная проблема безопасности с важностью, доказательством, источником, стандартами и рекомендацией/плейбуком. |
| **Отпечаток ПО** | Название и версия программы, извлечённые из документов, баннеров или веб-заголовков. |
| **Пассивный режим** | Ноль запросов к целевым хостам: только внешние открытые источники и архивы ([ADR-0009](../../adr/0009-passive-never-touches-target.md)). |
| **Перебор поддоменов** | Проверка имён из словаря против DNS цели (только «Стандартный» и «Полный»). |
| **Перебор путей** | Проверка типовых адресов на сайте (бэкапы, `.env`, `.git`, листинги) по словарю: «Поиск забытых файлов». |
| **Песочница плагинов** | Изолированная среда чистого Rust (декларативные JSON/TOML или ограниченный по памяти/`fuel` WASM) без доступа к ФС, сырым сокетам и `KeyVault`. |
| **Поддомен** | Имя внутри домена: `mail.example.com`, поддомен `example.com`. |
| **Прокси** | Посредник для трафика: цель видит его адрес, а не ваш (например, Orbot/Tor или v2rayNG). |
| **Путь компрометации (Attack Path)** | Ранжированная цепочка атаки (`foca-analysis::attack_paths`), связывающая утёкшие документы/артефакты, логины/секреты, внутренние хосты и внешние точки входа. |
| **РНОКПП** | Регистрационный номер учётной карточки налогоплательщика (ІПН, 10 цифр). Хранится исключительно маской. |
| **Секрет** | Пароль, API-ключ, токен или вебхук в документе или скрипте. Скрыт до подтверждения отпечатком/PIN. |
| **Скоуп** | Список разрешённых сетевых целей и исключений, которые трогать запрещено. |
| **Словарь** | Список путей или имён поддоменов для перебора (встроенные, SecLists, пользовательские). |
| **Уровень доступа** | Классификация запроса в ядре: `Passive` (сторонний сервис), `TouchesTarget` (хост цели), `Active` (активная фаза). Уровни `external` / `target` / `active` соответствуют профилям Пассивный / Стандартный / Полный. |
| **Флейворы `foss` / `play`** | Два варианта Android-сборки: `foss` (100% свободная `GPL-3.0` для F-Droid, без Google ML Kit) и `play` (с опциональным локальным OCR ML Kit). |
| **Цель** | Авторизованная сетевая цель проверки: домен (`example.com`), маска `*.example.com`, `http(s)://url`, `ip`, `cidr` или `ip-диапазон`. (E-mail, ФИО, организации и ASN целями скана не являются.) |
| **Wildcard DNS** | DNS-зона, резолвящая любые несуществующие имена; многоуровневый фильтр отсеивает ложные поддомены. |
