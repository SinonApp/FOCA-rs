# Свой экземпляр SearXNG

↑ [Руководство пользователя](README.md) · [Источники](sources.md)

Публичные поисковики показывают капчу телефонам с общими IP (мобильный CGNAT, VPN, Wi-Fi провайдера), а FOCA-rs капчи не решает. Свой экземпляр SearXNG ходит в поисковики с IP вашего сервера и отвечает FOCA-rs обычным JSON, поэтому дорки работают и тогда, когда Startpage или Brave телефону отказывают.

FOCA-rs спрашивает ваши экземпляры **раньше** публичного пула SearXNG и поисковиков без ключа. Экземпляров может быть несколько: укажите их через запятую или по одному на строку. Экземпляр, который не отдаёт JSON или постоянно сбоит, до конца скана пропускается.

## Требования

- Адрес с **HTTPS и публичным именем хоста** (`https://search.example.org`). Обычный HTTP, `localhost`, имена `.local`/`.internal`, частные и зарезервированные IP-адреса не принимаются, как и любой другой адрес, который вводит пользователь.
- Включён **формат вывода JSON** (по умолчанию он выключен).

## Быстрый запуск в Docker

```sh
docker run -d --name searxng --restart unless-stopped \
  -p 127.0.0.1:8080:8080 \
  -v ./searxng:/etc/searxng \
  -e SEARXNG_BASE_URL=https://search.example.org/ \
  searxng/searxng
```

При первом запуске появится файл `./searxng/settings.yml`. Откройте его, добавьте `json` в форматы вывода и перезапустите контейнер:

```yaml
search:
  formats:
    - html
    - json
```

```sh
docker restart searxng
```

Для публичного имени поставьте контейнер за привычный HTTPS reverse proxy (Caddy, nginx, Traefik). Проверьте из любого браузера: `https://search.example.org/search?q=test&format=json` должен вернуть JSON, а не страницу ошибки (HTTP 403 значит, что `json` всё ещё нет в `formats`).

Держите экземпляр для себя: открытый экземпляр быстро находят боты, и тогда поисковики начинают ограничивать уже его. Закройте доступ на reverse proxy, например списком разрешённых IP. Встроенный `limiter` SearXNG (защита от ботов) считает запросы к API ботами, поэтому, если экземпляром пользуетесь только вы, держите его выключенным.

## Подключение в FOCA-rs

1. **«Настройки → Ключи API → SearXNG»**.
2. Вставьте адрес (или несколько через запятую) в поле «Адреса экземпляров».
3. Нажмите **«Проверить экземпляры»**: у каждого адреса появится «отвечает JSON, результатов: N» или причина отказа (нет JSON, адрес не HTTPS или не публичный, нет ответа, лимит запросов).
4. Нажмите **«Сохранить»**. Адрес хранится в зашифрованном виде, как и ключи API (Android Keystore), а источник `searx` включается сам.

Во время скана карточка `searx` на экране скана показывает его статус. Если экземпляр отвечает 429 или 503, источник замедляется, а при повторах останавливается до конца скана со статусом «лимит запросов».

## Brave Search API

На том же экране можно указать необязательный ключ Brave Search API: это ещё один поисковик для дорков, без капчи. Кнопка проверки показывает, сколько запросов осталось в этом месяце. Бесплатного тарифа у Brave нет: нужна карта, в каждом тарифе есть ежемесячный кредит $5 (около 1000 запросов). Подробнее: [Источники](sources.md#таблица-источников).
