# Руководство пользователя FOCA-rs

[English](../../user/README.md) | Русский

↑ [Документация](../README.md) · [Корень репозитория](../../../README.ru.md)

FOCA-rs 2.0.0-beta.4.1.1: Android-приложение (Tauri 2 + чисто-Rust ядро) для разведки по открытым источникам (OSINT), форензики метаданных публичных документов и анализа поверхности атаки организации. Мобильное переосмысление FOCA (ElevenPaths).

> ⚠️ Проверяйте только свою инфраструктуру или инфраструктуру заказчика с его письменного разрешения.
> Подробно: [Что законно](getting-started.md#что-законно).
